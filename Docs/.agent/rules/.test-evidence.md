# TEST-EVIDENCE.md

This file is the record of test results. The rules for tests live in TESTING.md.

## Rules

- Add a row when you write a test. Set its Status to "Written, not run". Why: the user can see what exists and what still needs a run.
- Status values: **Written, not run**, **Passed**, **Failed**.
- Mark a test Passed only if you ran it and saw it pass (Run by: agent), or the user reports a pass (Run by: user). Why: "Passed" is a release fact.
- In the Evidence column put the command you ran, or the user's own words. Why: a pass with no evidence cannot be checked.
- Never edit a row to hide a failure. Set it to Failed. Why: a quiet fix hides a real defect.
