# Spreadsheet-Safe CSV Export

## Procedure

1. Read PRD §§11 and 18 and the applicable project instructions before changing or reviewing export logic.

2. Receive the validated canonical cleaned CSV from the cleaning workflow.

3. Keep the canonical cleaned data unchanged. Generate spreadsheet-safe output as a separate representation.

4. Inspect parsed cell values for potentially dangerous formula-like prefixes, including:
   - `=`
   - `+`
   - `-`
   - `@`
   - Relevant leading whitespace and control characters before formula-like content.

5. Preserve confidently recognised legitimate numeric values, including negative numbers, where the approved classification is reliable.

6. Apply the approved neutralisation policy to suspicious text values. Use the isolated export-safety module and the approved apostrophe-prefix mitigation.

7. Count each affected cell once. Record the total number of values modified for export safety.

8. Serialize the protected cell values as UTF-8 CSV with correct quoting and escaping for commas, quotes and line breaks.

9. Preserve the original headers, column order and remaining record order. Do not add internal IDs or metadata columns.

10. Validate the canonical output and spreadsheet-safe output independently. Check CSV structure, row and column counts, and expected content.

11. Store both required output objects privately using deterministic identifiers.

12. Confirm successful storage before persisting the final metadata and summary.

13. Mark the cleaning run completed only after both outputs, required metadata and summary are durable.

14. Make preview and download available only after successful publication and authenticated ownership checks.

15. Use authenticated streaming or short-lived signed URLs. Never expose public buckets or permanent storage URLs.

16. Disclose that potentially dangerous values were protected. Do not claim that the mitigation guarantees identical behaviour across every spreadsheet application.

17. Verify the applicable export acceptance tests, including Excel and LibreOffice behaviour, protection counts, retries and publication only after validation.

## Completion checks

- Canonical cleaned data remains unchanged by export protection.
- Spreadsheet-safe output is separately generated and validated.
- Protection counts and user disclosure are recorded.
- Both required objects are stored privately.
- No partial or unvalidated output is published.
