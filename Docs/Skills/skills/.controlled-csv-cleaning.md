# Controlled CSV Cleaning

## Procedure

1. Read PRD §9 and the applicable project instructions before implementing or reviewing cleaning logic.

2. Confirm that the requested cleaning run belongs to the authenticated user and references an eligible source upload.

3. Retrieve the user's explicitly selected cleaning operations.

4. Reject an empty or unsupported selection. At least one approved operation must be selected.

5. Before creating the cleaning run, present:
   - The selected operations.
   - An explanation of each operation.
   - A warning about records removed by row-removal operations.
   - Confirmation that the original upload remains unchanged.

6. Require explicit user confirmation before creating the cleaning run.

7. Parse the original CSV and preserve its headers, column order and remaining record order.

8. Apply selected operations in the exact PRD order:
   - Trim supported leading and trailing whitespace.
   - Remove fully blank rows, if selected.
   - Remove exact duplicate rows, if selected, keeping the first occurrence.

9. Do not perform unsupported cleaning. Do not fill missing values, guess formats, change casing, edit individual cells or alter business values outside the selected operations.

10. Generate the canonical cleaned CSV.

11. Validate the generated CSV structure and run the same four data-quality checks against the cleaned output.

12. Prepare the cleaning summary and remaining findings required by PRD §9.

13. Pass the canonical output to the spreadsheet-safe export procedure. Do not implement export-safety transformations inside the canonical cleaning operation.

## Completion checks

- Only confirmed operations were applied.
- Operations ran in the required order.
- The original upload was not modified.
- Headers and column order were preserved.
- Cleaning counts and remaining findings were recorded.
- The canonical output passed validation.
