# CSV Data Quality Analysis

## Procedure

1. Read PRD §8 and the applicable project instructions before changing or reviewing analysis logic.

2. Use only an upload that has passed CSV validation.

3. Parse the accepted CSV and preserve the original parsed values for analysis.

4. Exclude the header row from all data-quality checks.

5. Identify missing values:
   - Count empty cells and whitespace-only cells.
   - Exclude fully blank rows from the main missing-value count.
   - Record the number of fully blank rows ignored.
   - Do not automatically classify `0`, `0.00`, `N/A`, `NA`, `NULL`, `null`, `-`, `unknown` or `not provided` as missing.
   - Report affected columns and counts.

6. Identify exact duplicate rows:
   - Exclude fully blank rows.
   - Compare all parsed data-column values as strings.
   - Do not trim, change casing or normalise values before comparison.
   - Count duplicate occurrences beyond the first occurrence.
   - Do not infer duplicates from a single column.

7. Assess inconsistent formats:
   - Use only explicitly documented and supported patterns.
   - Require at least 80% matching non-empty values and at least two distinct non-empty values.
   - Exclude empty and whitespace-only values from the denominator.
   - Do not infer data types from column names.
   - Do not guess ambiguous dates or numeric conventions.
   - Return `NOT_ASSESSED` when evidence is insufficient or competing patterns make classification ambiguous.
   - Record the required detection metadata.

8. Identify unnecessary whitespace:
   - Check leading and trailing spaces, tabs, line breaks and supported Unicode whitespace.
   - Do not flag spaces between words.
   - Exclude headers and fully blank rows.
   - Do not count whitespace-only cells again as whitespace issues.
   - Count each affected cell once.

9. Keep analysis read-only. Do not clean, delete, fill, normalise or otherwise modify source values.

10. Produce the findings and counts required by PRD §8.

11. Verify deterministic repeatability and the applicable acceptance tests in PRD §8.

## Completion checks

- All four required detection categories have an outcome.
- Findings follow the approved counting and classification rules.
- Ambiguous format results are not guessed.
- Original data remains unchanged.
- Results are reproducible.
